# 🤖 Telegram-бот для приёма заявок с ИИ-сводкой

Бот принимает заявки от пользователей, хранит их в базе SQLite
и умеет делать автоматическую сводку за день через ИИ.

## Возможности
- 📝 Приём заявок через диалог
- 📋 Просмотр своих заявок
- 🔔 Уведомление владельца
- 📊 Админ-панель
- 📥 Экспорт в CSV
- 🤖 ИИ-сводка по заявкам за день (/summary)

## Стек
Python, python-telegram-bot, SQLite, Ollama (llama3.2)

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с токеном бота
3. Запустите: `python bot.py`
