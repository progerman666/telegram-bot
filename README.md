# 🤖 Telegram-бот для приёма заявок

Портфолио-кейс: **Python + python-telegram-bot + SQLite + логирование**.

Бот принимает заявки от пользователей, сохраняет их в базу данных SQLite, уведомляет владельца и позволяет админу просматривать и выгружать все заявки.

## ✨ Возможности

- 📝 Приём заявок через диалог с кнопками
- 📋 Просмотр своих заявок пользователем
- 🔔 Уведомление владельца при каждой новой заявке
- 📊 Админ-панель: просмотр всех заявок
- 📥 Экспорт всех заявок в CSV
- 🔒 Безопасное хранение токена (переменная окружения)
- 🛡️ Защита от SQL-инъекций (параметризованные запросы)
- 📏 Лимит длины текста заявки

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/progerman666/telegram-bot.git
cd telegram-bot
```

### 2. Создайте виртуальное окружение

```bash
python -m venv myenv
```

### 3. Активируйте окружение

**Windows:**
```bash
myenv\Scripts\activate
```

**Linux/Mac:**
```bash
source myenv/bin/activate
```

### 4. Установите зависимости

```bash
pip install -r requirements.txt
```

### 5. Настройте переменные окружения

Создайте файл `.env` в корне проекта:

```
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_телеграм_id
```

### 6. Запустите бота

```bash
python bot.py
```

## 🚂 Деплой на Railway

1. Загрузите код на GitHub
2. На [railway.app](https://railway.app) создайте проект из репозитория
3. В разделе **Variables** добавьте `BOT_TOKEN` и `ADMIN_ID`
4. Railway автоматически соберёт и запустит бота
