# 🤖 Telegram-бот для приёма заявок

Портфолио-кейс: **Python + python-telegram-bot + SQLite + логирование**.

Бот принимает заявки от пользователей, сохраняет их в базу данных SQLite,
уведомляет владельца и позволяет админу просматривать и выгружать все заявки.

## ✨ Возможности

- 📝 Приём заявок через диалог с кнопками
- 📋 Просмотр своих заявок пользователем
- 🔔 Уведомление владельца при каждой новой заявке
- 📊 Админ-панель: просмотр всех заявок
- 📥 Экспорт всех заявок в CSV
- 🔒 Безопасное хранение токена (переменная окружения)
- 🛡️ Защита от SQL-инъекций (параметризованные запросы)
- 📏 Лимит длины текста заявки
